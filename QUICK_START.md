# WayFair - Quick Start Guide

## 🚀 Get Started in 5 Minutes

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection
- JavaScript enabled

### 1. Access the Application
```
Open: http://localhost:8000 (or your deployment URL)
```

### 2. Create an Account

#### As a Passenger:
1. Click "Get Started"
2. Select "Passenger"
3. Enter email and password
4. Verify your email
5. Complete your profile

#### As a Driver:
1. Click "Get Started"
2. Select "Driver"
3. Enter email and password
4. Verify your email
5. Upload documents
6. Complete your profile

### 3. First Ride

#### Book a Ride (Passenger):
1. Go to Dashboard
2. Click "Search Rides"
3. Enter destination
4. Select a ride
5. Click "Book Now"
6. Complete payment
7. Track your ride in real-time

#### Offer a Ride (Driver):
1. Go to Dashboard
2. Click "Create Ride"
3. Enter route details
4. Set price
5. Click "Submit"
6. Wait for passengers to book
7. Start your ride

### 4. Essential Features

#### Live Tracking
- Click "Track Live" in active rides
- See real-time driver location
- Chat with driver

#### Payments
- Secure payment via Stripe
- View transaction history
- Refund requests available

#### Chat
- Message driver/passenger
- Share location
- Report issues

#### Ratings
- Rate driver/passenger after ride
- Write reviews
- Help community

### 5. Admin Access

#### Login as Admin:
1. Go to login page
2. Check "Admin Mode"
3. Email: `admin@wayfair.com`
4. Password: `admin123`
5. Access admin dashboard

#### Admin Features:
- View all users
- Manage documents
- Handle reports
- View statistics
- Block users

### 6. Settings

#### Profile Settings:
- Update personal info
- Add emergency contacts
- Set preferences
- View documents

#### Accessibility:
- Dark mode
- Font size adjustment
- High contrast
- Reduce motion

#### Notifications:
- Enable/disable types
- Customize preferences
- Manage alerts

### 7. Safety Features

#### SOS Button:
- Available in live rides
- Alerts emergency services
- Notifies trusted contacts
- Shares your location

#### Trusted Contacts:
- Add emergency numbers
- Share ride details
- Get alerts

### 8. Referral Program

#### Share & Earn:
1. Go to "Referral"
2. Copy your code
3. Share with friends
4. Earn $10 per signup
5. Get bonuses for rides

### 9. Common Issues

#### Can't log in?
- Check internet connection
- Verify email
- Reset password
- Clear browser cache

#### Payment declined?
- Check card details
- Try different payment method
- Contact support

#### Location not updating?
- Enable location permission
- Refresh page
- Check GPS
- Update browser

#### Offline features?
- App works offline
- Some features cached
- Auto-syncs when online
- Check status
